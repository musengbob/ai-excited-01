Rooftop Whale — a colossal humpback whale bursts vertically out of a tiny rooftop infinity pool on a glass skyscraper at golden sunset. Water explodes outward in a crown of spray and cascades down the tower in waterfalls while tiny people on the roof point and run in awe. Impossible scale, a whale where it cannot belong, frozen at the single most thrilling moment.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program validates `entry.png` (JPEG, 1024x1024, under 1 MiB) and copies it byte-for-byte to `out/entry.png`. Run `node main.ts --help` for usage.
